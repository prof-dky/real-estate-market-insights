# real estate market insights dashboard

This project analyzes property listing data to show how traffic, leads, and conversions change across locations and price ranges.

It is a project based on the type of work done in real estate and market trend analysis roles.

---

## objective

Use SQL, Python and Power BI to:

- clean and prepare raw listing data  
- measure views, leads and conversion by location  
- compare price bands against engagement  
- produce clear visuals and insights summary
